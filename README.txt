ANGLE ADVENTURES: The Wonderful World of Hidden Angles
Grade 7 (CBSE) interactive presentation - about 25 minutes, 8 slides

RUN OFFLINE
  Double-click index.html (or drag it into Chrome, Edge, Firefox or Safari).
  No internet, server, fonts or installs are needed. Everything is in that one file.

CONTROLS
  Next ............ Right arrow, Space, Page Down, or the "Next" button
  Back ............ Left arrow or Page Up
  N ............... teacher notes (timings + talking points)
  F ............... fullscreen
  Wave icon ....... reduced-motion mode (it also turns on automatically when the OS asks for less motion)
  Restart icon .... back to slide 1

Inside a slide, Next first plays the slide's next build step. It moves to the
next slide only when the current slide is finished. If a question is still
unanswered, Pip reminds the class to predict first. On slides 2 and 5, pressing
Next a second time reveals the answer, so the teacher can always move on.
